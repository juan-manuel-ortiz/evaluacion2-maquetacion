
# Aula Ágil

Evaluación 2 - Maquetación dinámica

**Aprendiz:** Juan Manuel Ortiz Mena  
**Tema:** 9 - Academia de cursos cortos  
**Empresa:** Aula Ágil

## Descripción

Desarrollé una página web para Aula Ágil, una academia que ofrece cursos cortos para aprender habilidades prácticas.

La página muestra 12 cursos organizados en cuatro categorías: programación, diseño, idiomas y ofimática.

## Funcionalidades

- Mostrar los 12 cursos mediante tarjetas.
- Filtrar los cursos por categoría.
- Buscar cursos por nombre o descripción.
- Ordenar los cursos por nombre o por horas.
- Mostrar la cantidad de resultados.

## Tecnologías utilizadas

- HTML
- CSS
- Bootstrap 5.3
- JavaScript
- Git y GitHub
